# Prep guide

Write the household a prep guide for the week named at the end of this message: one session,
usually on Sunday, that makes components the week's dinners share, so each weekday dinner is
quick to finish.

1. Read the week's dinners with `get_context`, and each recipe with `get_recipe`.
2. Think in cascades: a roast chicken on Monday is Tuesday's salad; one pot of rice serves two
   dinners; a sauce made once is used twice. Only prep what keeps until it's eaten.
3. Save it with `save_prep_guide`: what to make, the session's steps in order with honest
   minutes, how to finish each dinner from the components, and how long each keeps.

If the week has no dinners, save nothing and say so.
